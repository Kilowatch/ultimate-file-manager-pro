# Security Policy

| Version | Supported          |
|---------|--------------------|
| 1.7.x   | :white_check_mark: |
| 1.6.x   | :white_check_mark: |
| < 1.6   | :x:                |

## Reporting a Vulnerability

We take the security of Ultimate File Manager Pro seriously. If you discover a security vulnerability, **please do NOT open a public issue on GitHub** — instead, report it privately so we can address it before it is disclosed publicly.

### How to Report

Send an email to **support@kilowatch.co.za** with the following details:

- **Subject**: `[UFM Security] <brief description>`
- **App version** you are using (you can find this in Settings → About or in the Play Store listing)
- **Device model and Android version**
- **A detailed description of the vulnerability**
- **Steps to reproduce** the issue (the more specific, the better)
- **Proof of concept** or exploit code (if applicable)
- **Impact assessment** — what an attacker could achieve by exploiting this

### What to Expect

- **Acknowledgment**: You will receive an acknowledgment of your report within **48 hours**.
- **Updates**: We will keep you informed of the progress toward a fix at reasonable intervals.
- **Disclosure**: Once a fix has been developed, tested, and released, we will coordinate disclosure timing with you. We aim to publish a security advisory and credit you (if you wish) in the release notes.

Thank you for helping keep UFM and its users safe.
