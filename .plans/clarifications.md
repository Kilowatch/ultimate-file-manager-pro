## Confirmed Decisions

### 1. In-App Favorite Tile Subtitle Format
- **Decision:** Keep the primary title/label as-is. In the subtitle position (where it currently says `"Favorite folder"` or `"Favorite file"`), replace it with the dynamic connection protocol and item type:  
  `"{Protocol} • {Type}"` (e.g., `"WebDAV • Folder"`, `"WebDAV • File"`, `"SMB • Folder"`, `"SMB • File"`, `"NFS • Folder"`, `"FTP • Folder"`, `"Local • Folder"`).
- **Scope:** Main Storage grid/list tiles (`StorageBrowserActivity`, `StorageAdapter`) and the Manage Favorites screen (`ManageFavoritesActivity`).

### 2. Network / WebDAV File Launch Behavior from Home Screen Shortcut
- **Decision:** Open `NetworkBrowserActivity` navigating to the file's parent directory, and automatically launch the file via the player/viewer router (`EXTRA_OPEN_FILE_PATH`).
- **Resilience:** If the connection requires authentication or streaming buffering, the parent directory context is preserved and the file viewer/player initiates smoothly.

### 3. "Remove from Home Screen" UX & Explanatory Dialog
- **Decision:** Present a clear confirmation dialog explaining Android's OS security architecture limitation:  
  *"Due to Android security restrictions, apps cannot directly remove icons from your home screen. The shortcut will be disabled. To remove it completely, please drag the icon to Remove or Uninstall on your launcher."*
- **Action Buttons:** `[Disable Shortcut]` (proceeds with disable) and `[Cancel]` (aborts).

### 4. Visual Protocol Badging on Home Screen Launcher Shortcut Icons
- **Decision:** Overlay a compact, high-contrast protocol badge/pill (e.g. `WDAV`, `SMB`, `NFS`, `FTP`, `CLOUD`) onto the shortcut icon canvas rendered by `FavoriteIconComposer`.
- **Label:** Keep the shortcut label clean with the user-defined favorite name.
